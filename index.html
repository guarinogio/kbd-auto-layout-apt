📦 Install

1. Add the signing key

curl -fsSL https://guarinogio.github.io/kbd-auto-layout-apt/public.key \ | sudo gpg --dearmor --yes -o /usr/share/keyrings/kbd-auto-layout.gpg

2. Add the APT repository

echo "deb [signed-by=/usr/share/keyrings/kbd-auto-layout.gpg] https://guarinogio.github.io/kbd-auto-layout-apt stable main" \ | sudo tee /etc/apt/sources.list.d/kbd-auto-layout.list

3. Install

sudo apt update && sudo apt install kbd-auto-layout

4. Enable the service

systemctl --user enable --now kbd-auto-layoutd

🚀 Quick Start

Automatic setup (wizard)

kbd-auto-layoutctl setup

The wizard detects your keyboards, asks which one to use for US English, and creates the rule for you.

Manual configuration

Edit ~/.config/kbd-auto-layout/config.ini:

[general]
default_layout = es
default_variant = nodeadkeys
poll_interval = 2
backend = auto

[device "Keychron K2 Max"]
layout = us
match = contains
priority = 20

❓ FAQ

My Bluetooth keyboard doesn't switch layouts
Bluetooth keyboards often don't report hardware IDs. Use match = contains and omit vendor_id/product_id from the rule. Run kbd-auto-layoutctl detect to see the exact device name, then use a substring of it.
What's the difference between "exact" and "contains" matching?
exact matches the full device name. contains matches if the device name contains your pattern. Use contains for Bluetooth keyboards where the name may vary slightly.
Does this work on Wayland?
Yes, with GNOME. Set backend = auto (default). For other Wayland compositors, the daemon will gracefully fall back and log a warning.
Can I use multiple external keyboards with different layouts?
Yes. Create one [device] section per keyboard. Rules with higher priority win when multiple match.
How do I uninstall?
sudo apt remove kbd-auto-layout then remove the APT source file and GPG key.
